# ⚡ AI Code Forge — Unified Multi-Model Engine

A single HTML file that runs in any browser. Enter multiple AI API keys, run all models in parallel, combine their outputs, and download the result as a real code file.

## 🚀 How to Host on GitHub Pages (Free)

1. Go to [github.com](https://github.com) and create a new repository
2. Name it `ai-code-forge` (or anything you want)
3. Upload `index.html` to the repository
4. Go to **Settings → Pages**
5. Under "Source" select **main branch**
6. Click Save — your site is live at:
   `https://YOUR_USERNAME.github.io/ai-code-forge`

## ✨ Features

- **Multi-model parallel execution** — All active models run at the same time
- **Smart combiner** — Merges best parts from all responses
- **5 AI providers** — OpenAI, Anthropic, Google Gemini, Mistral, Groq
- **Auto key validation** — Tests your keys instantly
- **Max token control** — Up to 32,768 tokens per model
- **File download** — Export as .py, .js, .ts, .html, .jsx, and more
- **Syntax highlighting** — Live colored code output
- **No backend needed** — Pure client-side, single HTML file

## 🔑 Supported API Keys

| Provider | Where to get key |

> **Note:** Groq has a free tier — great for testing!

## 💡 Tips

- Add more than 1 key to get combined super-output
- Set **Max Tokens** to 32,768 for maximum code length
- Use **Deep Merge All** strategy for the most complete output
- Temperature 0.0 = most precise code output
